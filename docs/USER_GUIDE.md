# VP App 운영자 사용 설명서

버전 0.7.7 기준

이 문서는 전시장·공연장·사이니지 현장에서 웹 화면으로 VP App을 매일 운영하는 분을 위한 설명서입니다.
설치와 네트워크 구성은 [설치·네트워크 구성 가이드](INSTALL_GUIDE.md), AMX 등 외부 컨트롤러 연동은
[AMX/TCP 연동 매뉴얼](TCP_PROTOCOL.md)을 참고하세요.

화면에 표시되는 메뉴·버튼 이름은 이 문서에서 `굵은 글씨` 또는 따옴표로 표기합니다. 대부분의 아이콘 버튼은
마우스를 올리면 이름(툴팁)이 표시되므로, 문서의 이름과 툴팁을 맞춰 보며 찾으면 됩니다.

## 1. 개요

VP App은 Windows PC에서 동작하는 미디어 재생 시스템입니다. 한 대의 PC에 연결된 여러 모니터에 출력 창을
배치하고, 영상·이미지·음원을 재생목록으로 묶어 재생합니다.

제어 방법은 두 가지입니다.

| 제어 방법 | 용도 |
| --- | --- |
| 웹 화면 | 운영자가 브라우저로 접속해 파일·재생목록·화면 배치·설정을 관리하고 재생을 제어합니다. |
| TCP 외부제어 | AMX 등 AV 컨트롤러가 네트워크로 재생·정지·재생목록 선택 등을 명령합니다. |

주요 기능은 다음과 같습니다.

- 여러 모니터에 출력 창을 자유롭게 배치하고 프리셋으로 저장·복원
- 두 가지 재생목록 방식: **장면형**(모든 창이 함께 진행) / **윈도우형**(창마다 독립 재생)
- 재생 전 메모리 프리로드(로딩)로 지연 없는 시작과 전환
- 마스터 볼륨, 창별 오디오 출력 장치, 채널별 출력·볼륨·지연 설정
- 네트워크 영상 입력(RTSP / SRT / RTP / UDP, 환경에 따라 NDI)
- 여러 PC를 묶어 동시에 재생하는 멀티 PC 동기

## 2. 화면 구성

### 2.1 접속

같은 네트워크의 PC·태블릿에서 브라우저를 열고 다음 주소로 접속합니다.

```
http://<VP App이 설치된 PC의 IP 주소>:3000
```

VP App이 설치된 PC 자신에서는 `http://localhost:3000` 으로 접속할 수 있습니다. 웹 포트를 변경한 경우
`3000` 대신 변경한 포트 번호를 사용합니다.

### 2.2 상단 바

| 항목 | 설명 |
| --- | --- |
| **플레이어 컨트롤** (로고) | 누르면 홈 화면으로 이동합니다. |
| 장면 모드 / 윈도우 모드 토글 | 현재 선택된 재생목록의 방식을 표시하고 전환합니다. [6.7 재생목록 방식 전환](#67-재생목록-방식-전환) 참고. |
| 메모리 표시 (`가용`) | PC의 가용 메모리를 표시합니다. 마우스를 올리면 세부 사용량이 보입니다. |
| 언어 (`KO` / `EN`) | 화면 언어를 한국어 / English 중에서 고릅니다. 이 설정은 접속한 브라우저에만 저장됩니다. |
| 라이트 모드 / 다크 모드 | 화면 밝기 테마를 전환합니다. |

### 2.3 왼쪽 메뉴

넓은 화면에서는 아이콘만 표시되며, 아이콘에 마우스를 올리면 이름이 보입니다. 좁은 화면에서는 왼쪽 위
메뉴(≡) 버튼으로 엽니다.

| 그룹 | 메뉴 | 내용 |
| --- | --- | --- |
| (운영) | **홈** | 운영 화면. 재생 상태, 빠른 실행, 프리셋 불러오기, 마스터 볼륨 |
| (운영) | **플레이어** | 멀티 PC 마스터 콘솔. 이 PC가 Master로 설정된 경우에만 표시 |
| 콘텐츠 | **재생목록** | 재생목록 만들기·편집 |
| 콘텐츠 | **파일** | 미디어 파일 업로드·정리 |
| 콘텐츠 | **라이브 소스** | 네트워크 영상 입력 등록 |
| 출력 | **화면 구성** | 출력 창 추가·배치, 화면 구성 프리셋 |
| 시스템 | **설정** | 네트워크, 시작, 재생, 오디오, 동기화, 시스템 설정 |
| 시스템 | **도움말** | 터미널(TCP) 외부제어 가이드 |

### 2.4 하단 트랜스포트 바

홈을 제외한 모든 화면 아래쪽에 재생 제어 바가 항상 표시됩니다(홈에는 더 큰 같은 제어판이 있습니다).

| 버튼 / 요소 | 동작 |
| --- | --- |
| 시간 슬라이더 | 현재 재생 위치와 전체 길이. 끌어서 위치를 옮깁니다. |
| 미디어 이름 | 현재 장면 이름 또는 재생 중인 파일 이름. 없으면 "선택된 미디어 없음" |
| 마스터 볼륨 (스피커 아이콘) | 누르면 세로 볼륨 슬라이더가 열립니다. |
| **이전** / **다음** | 이전·다음 장면(또는 항목)으로 이동 |
| **재생** / **일시정지** | 재생과 일시정지 전환 |
| **정지** | 재생 정지 |
| **전체 정지 (모든 창)** | 윈도우형 재생 중에만 표시. 모든 창을 한 번에 정지 |
| 반복 | 누를 때마다 **반복 없음** → **전체 반복** → **한 곡 반복** 순서로 바뀝니다. |

윈도우형 재생 중에는 시간 슬라이더 위에 창 이름 탭이 나타납니다. 탭으로 창을 고르면 재생·일시정지·정지·
이전·다음·반복 버튼이 **선택한 창에만** 적용됩니다(툴팁이 "선택 창 재생", "선택 창 정지" 등으로 바뀝니다).

## 3. 처음 시작하기

처음 설치한 PC에서 재생까지 가는 기본 순서입니다.

1. **출력 창 만들기** — **화면 구성** 메뉴에서 `추가` → **출력 창 추가**를 누르고, 모니터와 위치를
   지정합니다. 출력 창이 없으면 재생목록을 편집할 수 없습니다. ([7장](#7-화면-구성출력-창-배치))
2. **오디오 장치 고르기** — **설정 › 오디오**에서 **오디오 출력 장치**를 선택합니다. ([8장](#8-오디오))
3. **파일 올리기** — **파일** 메뉴에서 **파일 업로드**로 영상·이미지·음원을 올립니다. ([5장](#5-파일-관리))
4. **재생목록 만들기** — **재생목록** 메뉴에서 **새 플레이리스트**를 만들고 장면(또는 창별 항목)을
   채웁니다. ([6장](#6-재생목록플레이리스트))
5. **로딩 후 재생** — 홈의 **플레이리스트 빠른 실행**에서 재생목록을 고르고 로딩 버튼으로 프리로드한 뒤
   재생합니다. ([4장](#4-홈-화면에서-운영하기))
6. **현장 자동화(선택)** — PC가 켜지면 자동으로 재생되게 하려면 **설정 › 일반 › 시작**에서
   **시작 시 자동 실행**과 **부팅 시 재생**을 켭니다. ([11장](#11-설정))

## 4. 홈 화면에서 운영하기

홈은 매일 운영에 쓰는 화면입니다. 왼쪽에 재생 상태와 큰 트랜스포트, 오른쪽에 빠른 실행과 볼륨이 있습니다.

### 4.1 재생 상태

- 상단 배지가 **재생 중** 또는 **정지**를 표시합니다.
- 현재 재생목록 이름과, 장면형 재생 중이면 몇 번째 장면인지(`· 장면 N`) 표시됩니다.
- 모니터 배치도에 출력 창 위치가 표시됩니다(홈에서는 보기 전용이며, 배치 변경은 **화면 구성**에서 합니다).
- 라이브 소스가 연결된 창이 있으면 배치도 아래에 창별 상태 점이 표시됩니다
  (초록 = 재생 중, 노랑 = 연결 중/재연결 중, 빨강 = 오류).
- **윈도우형** 재생목록에서는 창마다 칩이 표시되며, 칩에서 창별 **재생**, **정지**, 반복 전환을 할 수 있습니다.
- **장면형** 재생 중에는 각 창에서 재생 중인 파일 이름이 칩으로 표시됩니다.

### 4.2 플레이리스트 빠른 실행

1. **플레이리스트** 목록에서 재생할 재생목록을 고릅니다. 각 항목 옆에 **장면** / **윈도우** 방식이 표시됩니다.
2. 로딩 버튼(툴팁: "로딩 (메모리 프리로드 — 무지연 재생 준비)")을 누릅니다. 배지가 **로딩 중…** 에서
   **로딩됨** 으로 바뀌면 준비 완료입니다.
3. **재생** 버튼을 누릅니다.

장면형 재생목록을 로딩하지 않은 채 재생하면 "프리로딩 미완료" 확인창이 뜹니다. 그대로 재생하면 시작이
늦어지거나 창 사이 동기가 어긋날 수 있으므로, 공연·전시 시작 전에는 **취소**를 누르고 먼저 로딩하는 것을
권장합니다. 윈도우형 재생목록은 이 확인창이 뜨지 않습니다.

### 4.3 화면 구성 프리셋 불러오기

**화면 구성**에서 저장한 프리셋이 있으면 빠른 실행 아래에 **프리셋** 버튼들이 표시됩니다. 버튼을 누르면
그 배치가 바로 적용됩니다. 현재 적용된 프리셋은 채워진 버튼으로 표시됩니다.

### 4.4 마스터 볼륨

홈 오른쪽 아래의 **마스터 볼륨** 슬라이더(0–100)로 전체 출력 음량을 조절합니다. 끄는 동안 즉시 반영되고,
손을 떼면 값이 저장됩니다. 다른 화면에서는 하단 바의 스피커 아이콘으로 같은 볼륨을 조절합니다.

## 5. 파일 관리

**파일** 메뉴에서 재생에 쓸 미디어를 관리합니다. 왼쪽은 폴더, 오른쪽은 파일 목록입니다.

### 5.1 파일 업로드

1. 왼쪽 폴더 트리에서 파일을 넣을 폴더를 선택합니다(선택하지 않으면 **전체 파일**(최상위)).
2. 상단의 **파일 업로드** 버튼을 누릅니다.
3. 업로드 창에서 **파일 선택**을 누르거나 파일을 끌어다 놓습니다. 영상·이미지·음원 파일만 선택할 수 있습니다.
4. **파일 업로드**(구름 아이콘)를 눌러 전송합니다. 진행 중에는 **업로드 중단**으로 취소할 수 있습니다.
5. 끝나면 **닫기**를 누릅니다.

업로드 창의 **모두 지우기**는 대기 목록을 비우고, **업로드된 파일 제거**는 완료된 항목을 목록에서만 지웁니다
(서버에 올라간 파일은 그대로 남습니다).

### 5.2 파일 목록

| 열 | 내용 |
| --- | --- |
| 이름 | 파일 이름 |
| ID | 파일 번호 |
| 유형 | 파일 형식 |
| 크기 | 파일 크기 |
| 작업 | 아래 버튼들 |

**작업** 열의 버튼:

| 버튼 | 동작 |
| --- | --- |
| **웹 미리보기** (눈 아이콘) | 출력 화면이 아니라 브라우저 안에서 파일을 재생·표시합니다. |
| 정보 (i 아이콘) | 형식·코덱 등 파일 정보를 표시합니다. |
| **폴더로 이동** | 파일을 다른 폴더로 옮깁니다. |
| **저장** (다운로드 아이콘) | 파일을 내 컴퓨터로 내려받습니다. |
| **삭제** | 파일을 삭제합니다(확인창이 뜹니다). |

여러 파일을 한 번에 처리하려면 체크박스로 선택합니다. 목록 위에 "N개 선택됨"이 표시되고
**폴더로 이동**, **삭제**, **선택 해제** 버튼을 쓸 수 있습니다.

### 5.3 폴더

- 상단 **새 폴더** 버튼 또는 폴더 트리의 메뉴에서 **새 하위폴더**, **이름 변경**, **삭제**를 할 수 있습니다.
- 폴더를 삭제하면 하위 폴더는 함께 삭제되지만, **안에 있던 파일은 삭제되지 않고 전체 파일(최상위)로 이동**합니다.
- 폴더 트리 오른쪽 위의 화살표(**폴더 숨기기** / **폴더 보기**)로 폴더 패널을 접어 파일 목록을 넓게 볼 수 있습니다.

## 6. 재생목록(플레이리스트)

### 6.1 두 가지 방식

| 구분 | 장면형 (전 창 동시) | 윈도우형 (창별 독립) |
| --- | --- | --- |
| 구성 단위 | 장면. 한 장면 = 창마다 하나씩 배정한 영상 묶음 + 장면 오디오 | 창마다 따로 쌓은 항목 목록 |
| 재생 | 모든 창이 함께 시작하고 함께 다음 장면으로 넘어갑니다. | 창마다 따로 재생·정지하고, 창마다 따로 다음 항목으로 넘어갑니다. |
| 다음으로 넘어가는 시점 | 장면 안의 클립이 모두 끝났을 때(가장 긴 클립 기준) | 그 창의 현재 항목이 끝났을 때 |
| 반복 | 재생목록 전체에 하나 | 창마다 따로 지정 가능 |
| 어울리는 용도 | 여러 화면이 한 작품처럼 맞물리는 공연·미디어아트 | 화면마다 다른 콘텐츠를 도는 사이니지 |

### 6.2 재생목록 만들기·수정·삭제

1. **재생목록** 메뉴로 이동합니다.
2. 상단 **플레이리스트** 선택 상자를 열고 맨 아래 **새 플레이리스트**를 누릅니다
   (오른쪽 ⋮ 메뉴에서도 할 수 있습니다).
3. **새 플레이리스트 만들기** 창에서 입력합니다.
   - **플레이리스트 이름** (필수)
   - **플레이리스트 ID (자동 생성)** — 자동으로 채워지며 바꿀 수 있습니다. 다른 재생목록과 겹칠 수 없습니다.
   - **플레이리스트 타입** — **장면형 (전 창 동시)** 또는 **윈도우형 (창별 독립)**
   - **설명 (선택사항)**
4. **만들기**(체크 아이콘)를 누릅니다.

선택 상자 오른쪽의 `ID N` 배지는 재생목록 ID입니다. **AMX 등 TCP 외부제어에서 재생목록을 지정할 때 이 번호를
사용**하므로, 현장 컨트롤러 프로그램과 맞춰 관리하세요.

수정과 삭제는 오른쪽 ⋮ 메뉴의 **플레이리스트 편집**, **플레이리스트 삭제**를 사용합니다.

### 6.3 상단 버튼

| 버튼 | 동작 |
| --- | --- |
| 로딩 (툴팁: "로딩 (메모리 프리로드 — 무지연 재생 준비)") | 재생 없이 재생목록을 메모리에 미리 올립니다. 완료되면 **로딩됨** 배지 |
| **재생** | 이 재생목록을 재생합니다. |
| **트랙 추가** | 파일을 골라 재생목록 끝에 추가합니다. 폴더 필터와 **이름 검색**을 쓸 수 있습니다. |
| ⋮ | **새 플레이리스트**, **플레이리스트 편집**, **플레이리스트 삭제** |

### 6.4 장면형 편집

출력 창이 하나 이상 있어야 편집할 수 있습니다("출력 창이 없습니다…" 문구가 보이면 먼저 [7장](#7-화면-구성출력-창-배치)에서
창을 추가하세요).

**장면 만들기**

1. 오른쪽 위 **장면 추가**를 누르면 빈 장면이 맨 아래에 생깁니다.
2. 장면 카드의 **영상 추가**를 눌러 파일을 고릅니다. 영상은 **창마다 1개**이며, 창 수보다 많이 넣을 수 없습니다.
3. 추가된 영상 줄에서 선택 상자로 **어느 창에 띄울지** 고릅니다(같은 장면 안에서 이미 쓰는 창은 고를 수 없습니다).
4. 필요하면 영상 옆 타이머 칸에 **지연(ms)** 을 입력해 그 창의 시작을 늦춥니다.
5. 장면에 소리를 더하려면 **오디오** 영역을 펼쳐 **오디오 추가**를 누릅니다.

**장면 카드 사용법**

| 요소 | 동작 |
| --- | --- |
| 끌기 손잡이 (⋮⋮) | 끌어서 장면 순서를 바꿉니다. |
| 장면 이름 | 눌러서 이름을 지정합니다(최대 40자). 비우면 "장면 N"으로 표시됩니다. |
| 요약 | 영상 개수와 오디오 채널 수 |
| **이 장면부터 재생** | 이 장면부터 재생을 시작합니다. |
| **장면 삭제** | 장면을 삭제합니다. |
| **펼치기** / **접기** | 장면 내용을 펼치거나 접습니다. 재생목록을 처음 열면 모두 접혀 있습니다. |
| 영상 줄의 ⋮ | **영상 교체**, **제거** |

재생 중인 장면은 카드 테두리가 강조됩니다.

**참고 사항**

- 아무것도 넣지 않은 빈 장면은 재생할 때 건너뜁니다.
- 영상 없이 오디오만 있는 장면은 가장 긴 오디오 길이만큼 유지된 뒤 다음 장면으로 넘어갑니다.
- 이미지에 오디오를 함께 넣으면 그 오디오 길이만큼 표시됩니다. 오디오가 없으면 **설정 › 재생 › 이미지 표시 시간**(기본 5초)만큼 표시됩니다.
- **오디오 전용 창**(화면 송출 없음)에는 영상 대신 음원(또는 영상의 오디오)을 배정합니다.
- 오른쪽 위 스피커 버튼(**창별 오디오 뮤트**)으로 창별로 소리를 끄고 켤 수 있습니다. 뮤트된 창 수가 배지로 표시됩니다.

### 6.5 윈도우형 편집

출력 창마다 카드가 하나씩 표시되고, 카드 안에 그 창에서 차례로 재생할 항목을 쌓습니다.

**항목 추가**

1. 창 카드를 펼칩니다(창 이름 또는 화살표 클릭).
2. 카드 아래 `추가` → **영상 추가**(영상·이미지) 또는 **오디오 추가**(오디오 전용 항목)를 고릅니다.
   - 오디오 전용 항목은 재생 시 그 창에 배경만 표시되고 소리만 나며, 오디오 길이가 끝나면 다음 항목으로 넘어갑니다.
   - 오디오 전용 창은 **오디오 추가** 버튼 하나만 표시됩니다.
3. 끌기 손잡이로 항목 순서를 바꿉니다. 창 안의 순서가 재생 순서입니다.

**창 카드 버튼**

| 버튼 | 동작 |
| --- | --- |
| **창 오디오 뮤트** / **창 오디오 뮤트 해제** | 이 창의 소리를 끄고 켭니다. |
| **이 창 재생** | 이 창을 첫 항목부터 재생합니다. |
| **이 창 정지** | 이 창만 정지합니다. |
| 항목의 **이 항목부터 재생** | 그 항목부터 재생합니다. |
| 항목의 오디오 버튼 | 항목의 오디오 설정을 펼칩니다. 여기서 **오디오 추가**로 음원을 더할 수 있습니다. |
| 항목의 ⋮ | **교체**, **제거** |

재생 중인 창은 카드가 강조되고, 카드를 접어 두어도 현재 재생 중인 파일 이름이 표시됩니다.

### 6.6 반복

| 모드 | 장면형 | 윈도우형 |
| --- | --- | --- |
| **반복 없음** | 마지막 장면이 끝나면 정지 | 그 창의 마지막 항목이 끝나면 그 창 정지 |
| **전체 반복** | 마지막 장면 뒤 처음 장면으로 | 그 창의 마지막 항목 뒤 처음 항목으로 |
| **한 곡 반복** | 현재 장면을 반복 | 그 창의 현재 항목을 반복 |

- 장면형은 하단(또는 홈) 트랜스포트의 반복 버튼 하나로 정합니다.
- 윈도우형은 트랜스포트에서 창 탭을 고른 뒤 반복 버튼을 누르거나, 홈의 창 칩에 있는 반복 버튼으로 창마다 정합니다.
  창별로 따로 정하지 않은 창은 전체 반복 설정을 따릅니다.
- **이전** / **다음** 버튼은 반복 설정과 관계없이 수동으로 이동합니다.

### 6.7 재생목록 방식 전환

상단 바의 장면 모드 / 윈도우 모드 토글은 **현재 선택된 재생목록의 방식을 그 자리에서 변환**합니다.

- 장면형 → 윈도우형: 각 장면의 영상이 해당 창의 항목으로 나뉩니다.
- 윈도우형 → 장면형: 각 항목이 하나짜리 장면이 됩니다.

변환하면 재생목록 구성이 바뀌므로, 운영 중에는 실수로 누르지 않도록 주의하세요. 선택된 재생목록이 없을 때는
새로 만들 재생목록의 기본 방식만 바뀝니다.

### 6.8 프리로딩(로딩)

로딩은 재생목록의 클립을 미리 디코더에 준비해 두어 **누르는 즉시 시작**하고 **장면 전환 시 끊김이 없게** 하는
기능입니다. 상태 배지는 다음과 같습니다.

| 배지 | 의미 |
| --- | --- |
| **로딩됨** (초록) | 프리로드 완료, 바로 재생 가능 |
| **로딩 중…** (노랑) | 준비 중 |
| **미로딩** (회색) | 아직 로딩하지 않음 |

얼마나 앞까지 미리 준비할지는 **설정 › 재생 › 전 트랙 프리롤**에서 정합니다([11.2](#112-재생-탭)).

## 7. 화면 구성(출력 창 배치)

**화면 구성** 메뉴에서 출력 창을 만들고 모니터에 배치하며, 배치를 프리셋으로 저장합니다.

### 7.1 출력 창 추가

1. 오른쪽 위 `추가`를 누르고 고릅니다.
   - **출력 창 추가** — 화면에 영상을 내보내는 일반 창
   - **오디오 전용 창 추가 (화면 송출 없음)** — 화면 없이 소리만 내보내는 창
2. 왼쪽 모니터 배치도에 창이 사각형으로 나타납니다. 창을 끌어 옮기고, 오른쪽 아래 모서리를 끌어 크기를 바꿉니다.
   배치도에서 바꾼 위치·크기는 놓는 즉시 저장됩니다.

### 7.2 창 설정

배치도 아래 탭에서 창을 고르면 오른쪽에 설정이 표시됩니다. 이름·모니터·비율·위치·크기·표시 항목은 바꾼 뒤
**적용**(저장 아이콘)을 눌러야 반영됩니다. 오디오 장치, 뮤트, 오디오 전용, 라이브 소스는 바꾸는 즉시 반영됩니다.

| 항목 | 설명 |
| --- | --- |
| **이름** | 창 이름. 재생목록 편집과 트랜스포트에 표시됩니다. |
| **오디오 전용 (화면 송출 없음)** | 켜면 화면 창을 만들지 않고 소리만 냅니다. 영상 디코딩도 하지 않습니다. 전환하면 창이 다시 만들어져 재생 중인 내용이 멈춥니다. |
| **모니터** | 창을 띄울 모니터. **주 모니터** 또는 연결된 모니터 중에서 고릅니다. |
| **비율** | **레터박스**(비율 유지, 남는 부분은 배경) / **크롭(채움)**(비율 유지, 넘치는 부분 잘림) / **스트레치**(창에 맞게 늘림) |
| **고급 › 위치 · 크기 (px)** | X, Y, **너비**, **높이**를 숫자로 지정합니다. 너비/높이를 0으로 두면 모니터 전체를 채웁니다. |
| **고급 › 표시 › 배경색** | 창의 배경색 |
| **고급 › 표시 › Z 순서** | 창이 겹칠 때 쌓이는 순서. 숫자가 클수록 앞에 표시됩니다. |
| **오디오 › 출력 디바이스** | 이 창의 소리를 보낼 장치. [8.2](#82-창별-오디오-출력-장치) 참고 |
| **오디오 › 창 오디오 전체 뮤트** | 이 창의 소리를 모두 끕니다. |
| **라이브 소스** | 이 창에 연결할 네트워크 영상 입력. [9장](#9-라이브-소스) 참고 |
| **삭제** | 창을 삭제합니다. |

**모니터가 분리되었을 때**: 창의 대상 모니터가 연결되어 있지 않으면 모니터 항목에 **연결 안 됨**이 표시되고 창은
숨겨진 상태로 대기합니다. 모니터가 다시 연결되면 창이 자동으로 원래 자리에 나타납니다. 모니터는 순번이 아니라
모니터 고유 정보로 기억하므로, 재부팅이나 늦게 켜지는 모니터 때문에 순서가 바뀌어도 같은 모니터에 표시됩니다.

### 7.3 화면 구성 프리셋

현재 창 배치를 이름을 붙여 저장해 두고 필요할 때 불러올 수 있습니다.

| 작업 | 방법 |
| --- | --- |
| 저장 | 오른쪽 위 **프리셋 추가**(+)를 누르고 이름을 입력합니다. |
| 적용 | **프리셋** 선택 상자에서 고른 뒤 **적용**(▶)을 누릅니다. 현재 출력 창이 교체되므로 재생이 중단될 수 있습니다. |
| 덮어쓰기 | 프리셋을 고른 뒤 **현재 배치로 덮어쓰기**를 누릅니다. |
| 이름 변경 / 삭제 | 프리셋을 고른 뒤 **이름 변경** 또는 **삭제**를 누릅니다. |

현재 적용된 프리셋은 목록에 `· 현재`로 표시됩니다. 홈 화면에서도 프리셋 버튼으로 바로 적용할 수 있습니다.

## 8. 오디오

### 8.1 기본 오디오 출력 장치

**설정 › 오디오 › 오디오 출력 장치**에서 연필 버튼을 눌러 장치를 고릅니다. 목록에는 ASIO 장치가 먼저,
그 다음 WASAPI 장치가 표시됩니다. 창별 장치를 따로 지정하지 않은 창은 모두 이 장치로 출력됩니다.

### 8.2 창별 오디오 출력 장치

**화면 구성**에서 창을 고른 뒤 **오디오 › 출력 디바이스**를 지정하면 그 창의 소리(영상 소리, 라이브 입력 소리,
추가 오디오)를 다른 장치로 보낼 수 있습니다.

- **전역 디바이스 따름**: 8.1의 기본 장치를 사용합니다.
- 장치를 바꾸면 창이 다시 만들어지므로 재생 중인 내용이 멈춥니다. 운영 전에 설정하세요.
- **ASIO 장치는 동시에 1개만** 사용할 수 있습니다.
- 지정한 장치가 연결되어 있지 않으면 "지정한 장치가 연결돼 있지 않아 전역 디바이스로 출력합니다." 가 표시되고
  기본 장치로 출력됩니다.

### 8.3 마스터 볼륨과 뮤트

| 기능 | 위치 | 설명 |
| --- | --- | --- |
| 마스터 볼륨 | 홈, 하단 바 | 모든 소리가 합쳐진 뒤 최종 출력 음량(0–100) |
| 창 오디오 뮤트 | 화면 구성, 재생목록 편집 화면, 홈의 창 칩 | 창 단위로 소리를 끄고 켭니다. 운영 중 바로 적용됩니다. |
| 채널 뮤트 | 재생목록 오디오 표 | 특정 소스 채널만 끕니다. |

### 8.4 채널별 출력·볼륨·지연(오디오 표)

장면형의 장면 **오디오** 영역, 윈도우형의 항목 오디오 영역을 펼치면 오디오 표가 나타납니다. 영상에 내장된 소리와
추가한 오디오 파일이 **소스 채널 1개당 1줄**로 표시됩니다.

| 열 | 설명 |
| --- | --- |
| **소스 파일** | 소리가 나오는 파일. 영상 아이콘 = 영상 내장 오디오, 음표 아이콘 = 추가 오디오 |
| **볼륨** | 이 채널의 음량(0–100) |
| **뮤트** | 이 채널을 끕니다. |
| **출력** | 이 채널을 보낼 출력 채널(`Ch 1`, `Ch 2` …) 또는 **뮤트**. 선택지는 출력 장치의 채널 수에 맞춰 표시됩니다. |
| 지연 (타이머 칸, ms) | 이 채널의 출력을 늦춥니다. 10ms 단위로 조절합니다. |

- 예: 4채널 음원의 채널 1·2를 `Ch 1`·`Ch 2`로, 채널 3·4를 `Ch 3`·`Ch 4`로 보내 스피커별로 나눠 출력할 수 있습니다.
- 재생 중에 바꾼 값은 바로 반영되고 저장됩니다.
- 오디오가 없는 경우 "오디오 채널이 없습니다…" 문구가 표시됩니다. 영상에 내장 오디오가 있거나 오디오 파일을 추가하면 줄이 생깁니다.

## 9. 라이브 소스

**라이브 소스** 메뉴에서 카메라·인코더 등 네트워크 영상 입력을 등록합니다. 라이브 소스는 재생목록과 별개로
동작하며, 창에 연결하면 재생목록과 관계없이 그 창에서 계속 재생됩니다.

### 9.1 소스 등록

1. 오른쪽 위 **소스 추가**(+)를 누릅니다.
2. **이름**을 입력하고 **프로토콜**을 고른 뒤 항목을 채웁니다.

| 프로토콜 | 입력 항목 |
| --- | --- |
| **RTSP (카메라/인코더)** | **주소(URL)** — 예: `rtsp://192.168.0.10:554/stream1` |
| **SRT (저지연)** | **주소(URL)** — 예: `srt://192.168.0.10:9000?mode=caller` |
| **RTP** | **멀티캐스트 주소 (선택)**, **포트**(기본 5004), **코덱**(기본 `AUTO`). `AUTO`가 아니면 **페이로드 타입**, **클럭 레이트**도 입력 |
| **UDP (원본 MPEG-TS)** | **멀티캐스트 주소 (선택)**, **포트** |
| **NDI** | **NDI 소스 이름**, **주소 (ip:port, 선택)**. NDI 런타임이 설치된 PC에서만 목록에 나타납니다. |

3. 공통 항목을 정합니다.
   - **버퍼 지연(ms)** — 기본 200. 끊김이 잦으면 늘리고, 지연을 줄여야 하면 낮춥니다.
   - **오디오 수신** — 소스의 소리도 받을지 여부
4. **확인**을 누릅니다.

RTP의 **코덱**은 보통 `AUTO`(자동 감지)를 권장합니다. VLC 등에서 MPEG-TS를 RTP로 보내는 경우 `MP2T`를 선택합니다.
멀티캐스트 주소를 비워 두면 해당 포트로 들어오는 스트림을 받습니다.

### 9.2 창에 연결

1. **화면 구성**에서 창을 고릅니다.
2. **라이브 소스** 항목의 선택 상자에서 등록한 소스를 고릅니다(해제하려면 **없음**).
3. 고르는 즉시 연결되며, 옆에 상태가 표시됩니다.

### 9.3 상태 확인

**라이브 소스** 목록 오른쪽에 그 소스가 연결된 창과 상태 점이 표시됩니다(연결된 창이 없으면 "귀속된 창 없음").

| 상태 | 의미 |
| --- | --- |
| **연결 중…** | 소스에 접속하는 중 |
| **재생 중** | 정상 수신·표시 중 |
| **재연결 중…** | 끊겨서 다시 접속하는 중 |
| **오류** | 수신 실패. 주소·포트·네트워크를 확인하세요. |
| **중지됨** | 수신을 멈춘 상태 |

소스를 편집하려면 연필 버튼, 삭제하려면 휴지통 버튼을 누릅니다. 삭제하면 그 소스에 연결된 창은 연결이 해제됩니다.

## 10. 멀티 PC 동기

여러 대의 VP App PC를 한 네트워크에서 묶어 동시에 재생합니다. 한 대를 **Master(주)**, 나머지를 **Slave(종)**로
정하고, Master의 **플레이어** 메뉴에서 전체를 지휘합니다.

### 10.1 역할 설정 (모든 PC)

**설정 › 동기화 › 멀티 PC 동기화**에서 설정한 뒤 **적용**을 누릅니다.

| 항목 | 설명 |
| --- | --- |
| **역할** | **단독 (동기 안 함)** / **Master (주)** / **Slave (종)**. 기본값은 단독 |
| **클럭 소스** | **자동 (하드웨어 PTP 우선, 없으면 소프트웨어)** / **하드웨어 PTP (AES67/Dante)** / **소프트웨어 넷클럭 (VP 마스터)**. 보통 자동을 사용합니다. |
| **고급 › PTP 도메인** | 같은 그룹의 PC는 같은 값(기본 0) |
| **고급 › 리드타임** | 재생 명령 후 실제 시작까지 여유 시간(ms, 기본 1000) |
| **고급 › 멀티캐스트 주소 / 포트** | 재생 신호용 주소와 포트(기본 15002) |

- 위쪽 **PTP** 배지가 **동기됨**(초록)이면 시계가 맞춰진 상태입니다. **동기 대기**는 맞추는 중, **비활성**은 꺼진 상태입니다.
- Slave는 Master가 자동으로 찾아내므로 IP를 따로 입력하지 않습니다.
- Master로 설정하면 왼쪽 메뉴에 **플레이어**가 추가됩니다.
- 방화벽에서 UDP 319·320(PTP)과 재생 신호 포트가 허용되어야 합니다. 자세한 내용은
  [설치·네트워크 구성 가이드](INSTALL_GUIDE.md)를 참고하세요.

홈 화면의 빠른 실행 제목 옆에는 이 PC의 역할 배지(동기 상태에 따라 색 표시)가 나타납니다.

### 10.2 플레이어 목록 (Master)

**플레이어** 메뉴에서 발견된 PC가 카드로 표시됩니다(새로고침 버튼으로 다시 검색).

| 표시 | 내용 |
| --- | --- |
| **온라인** / **오프라인** | 접속 상태 |
| 역할 배지 | master / slave |
| PTP 배지 | 시계 동기 상태 |
| **재생 중** | 재생 중인 재생목록 이름, 없으면 **대기** |
| **관리** | 그 PC의 재생목록 목록을 열어 원격 재생·삭제. **파일** 버튼은 그 PC의 웹 화면을 새 탭으로 엽니다. |

발견된 플레이어가 없으면 다른 PC가 같은 네트워크에 있고 역할이 **Slave**로 되어 있는지 확인하세요.

### 10.3 쇼 구성과 재생 (Master)

**쇼** 영역에서 여러 PC가 무엇을 재생할지 정합니다.

1. **모드**를 고릅니다.
   - **미러 (동일 콘텐츠, 완전 락스텝)** — 모든 PC가 같은 재생목록을 완전히 맞춰 재생. **미러 재생목록**을 고릅니다.
     각 PC에 같은 콘텐츠(같은 재생목록)가 준비되어 있어야 합니다.
   - **분산 (플레이어별 콘텐츠, 시작 동기)** — PC마다 다른 재생목록을, 시작 시점만 맞춰 재생. **배정**에서 PC별
     **재생목록**을 고릅니다.
2. 필요하면 **PTP 도메인**, **리드 타임**(ms)을 조정합니다.
3. **쇼 저장**으로 구성을 저장합니다.
4. **쇼 재생**으로 시작, **쇼 정지**로 정지합니다.

### 10.4 동기 진단 (Master)

**동기 진단 (클럭 오차)** 표에서 각 PC의 **마스터 대비 오차**와 **왕복시간**을 확인합니다. **측정**을 누르거나
**자동**을 켜면 주기적으로 갱신됩니다. 오차 배지 색은 1ms 미만이면 초록, 10ms 미만이면 노랑, 그 이상이면 빨강입니다.

## 12. 소프트웨어 업데이트

웹 화면에서 업데이트 파일(`.vpu`)을 올려 VP App을 업데이트할 수 있습니다. 업데이트 파일은 공급사에서 제공합니다.

1. 재생 중인 내용이 없을 때 진행하는 것을 권장합니다(적용 시 재생이 중단되고 앱이 다시 시작됩니다).
2. **설정 › 시스템 › 소프트웨어 업데이트**에서 현재 버전(`현재 버전 vX.Y.Z`)을 확인합니다.
3. **업데이트 파일 선택**을 누르고 `.vpu` 파일을 고릅니다.
4. 업로드와 검증이 끝나면 "vA → vB 로 업데이트합니다…" 확인창이 뜹니다. 계속하려면 확인을 누릅니다.
   현재보다 새 버전이 아니면 별도의 경고가 표시됩니다.
5. "업데이트 적용 중… 앱이 재시작됩니다 (창을 닫지 마세요)" 동안 기다립니다.
6. 완료되면 "vX.Y.Z 으로 업데이트되었습니다." 가 표시됩니다.

업데이트에 실패하면 자동으로 이전 버전으로 되돌리고 그 사실을 표시합니다. 최근 업데이트 결과는 항목 아래에
`최근 업데이트: …` 또는 `최근 업데이트 실패: …` 로 남습니다.

| 메시지 | 조치 |
| --- | --- |
| 업데이트 파일을 복호화할 수 없습니다 | 이 제품용 업데이트 파일이 아니거나 파일이 손상되었습니다. 공급사에서 받은 파일인지 확인하세요. |
| VP App 업데이트 파일(.vpu)이 아니거나 손상되었습니다 | 파일을 다시 받아 시도하세요. |
| 설치 폴더에 쓰기 권한이 없습니다 | 최신 설치 파일로 한 번 재설치한 뒤 다시 시도하세요. |
| 다른 업데이트가 진행 중입니다 | 진행 중인 업데이트가 끝난 뒤 시도하세요. |
| 앱 재시작 확인 시간이 초과되었습니다 | 잠시 기다린 뒤 브라우저를 새로고침하세요. |

## 13. 문제 해결

### 13.1 자주 겪는 증상

| 증상 | 확인할 점 |
| --- | --- |
| 웹 화면에 접속되지 않음 | VP App이 실행 중인지, 주소와 포트(기본 3000)가 맞는지, 방화벽에서 허용되었는지 확인하세요. [설치·네트워크 구성 가이드](INSTALL_GUIDE.md) 참고 |
| "재생에 실패했습니다. 플레이어 연결을 확인하세요." / "메모리 정보 없음 (플레이어 미연결)" | 재생 엔진이 연결되지 않은 상태입니다. 잠시 기다린 뒤 다시 시도하고, 계속되면 VP App을 다시 시작하세요. |
| 재생목록 편집 화면에 "출력 창이 없습니다…" | **화면 구성**에서 출력 창을 먼저 추가하세요. |
| **장면 추가** / **영상 추가** 버튼이 눌리지 않음 | 출력 창이 없거나, 이미 창 수만큼 영상이 들어 있습니다. 창을 더 추가하세요. |
| 재생 시 "프리로딩 미완료" 확인창 | 장면형 재생목록을 로딩하지 않았습니다. **취소** 후 로딩 버튼을 누르고 **로딩됨**을 확인한 뒤 재생하세요. |
| 시작이 늦거나 장면 전환 때 끊김 | 재생 전 로딩을 했는지 확인하세요. 필요하면 **전 트랙 프리롤** 값을 늘리되 메모리 여유를 확인하세요. |
| 특정 창이 화면에 안 보임 | **화면 구성**에서 그 창 모니터에 **연결 안 됨**이 표시되는지 확인하세요. 모니터를 연결하면 자동으로 나타납니다. 창이 **오디오 전용**으로 되어 있지 않은지도 확인하세요. |
| 창이 다른 창에 가려짐 | **고급 › 표시 › Z 순서** 값을 조정하세요(클수록 앞). |
| 소리가 안 남 | 마스터 볼륨, 창 오디오 뮤트, 오디오 표의 채널 뮤트·출력(**뮤트**로 되어 있지 않은지), 오디오 출력 장치를 차례로 확인하세요. |
| 창별 장치를 지정했는데 기본 장치로 나옴 | 지정한 장치가 연결되어 있지 않습니다("지정한 장치가 연결돼 있지 않아…"). 장치 연결을 확인하세요. ASIO 장치는 동시에 1개만 쓸 수 있습니다. |
| 창 오디오 장치·오디오 전용을 바꿨더니 재생이 멈춤 | 정상 동작입니다. 이 설정을 바꾸면 창이 다시 만들어집니다. 운영 시작 전에 설정하세요. |
| 라이브 소스가 **오류** / **재연결 중…** 을 반복 | 송출 장비의 주소·포트·프로토콜, 네트워크 연결, 방화벽을 확인하세요. 끊김이 잦으면 **버퍼 지연(ms)**을 늘려 보세요. RTP는 **코덱**을 `AUTO`로 두는 것을 권장합니다. |
| 라이브 소스 프로토콜에 NDI가 없음 | 이 PC에 NDI 런타임이 설치되어 있지 않습니다. |
| **플레이어** 메뉴가 없음 | 이 PC의 역할이 **Master (주)**가 아닙니다. **설정 › 동기화**를 확인하세요. |
| 발견된 플레이어가 없음 / PTP가 **동기 대기**에서 안 바뀜 | 각 PC 역할(Slave), 같은 네트워크·같은 **PTP 도메인**인지, 방화벽(UDP 319·320 등)을 확인하세요. |
| 포트를 바꿨는데 그대로임 | 포트 변경은 VP App을 다시 시작해야 적용됩니다. |
| AMX에서 재생목록이 안 맞음 | 재생목록 화면의 `ID N` 배지 번호와 컨트롤러에 설정된 번호가 같은지 확인하세요. |

### 13.2 로그 파일

문제가 계속되면 로그 파일을 확인하거나 공급사에 전달하세요. 로그는 VP App이 설치된 PC의 다음 폴더에 저장됩니다.

```
%APPDATA%\vp_app2\logs
```

Windows 탐색기 주소창에 위 경로를 그대로 입력하면 폴더가 열립니다. 문의할 때는 VP App 버전(설정 › 시스템 ›
소프트웨어 업데이트에 표시), 증상이 발생한 시각, 로그 파일을 함께 전달하면 원인 파악이 빠릅니다.
