## 시작하기

### 설치

1. **다운로드**: [GitHub 릴리스 페이지](https://github.com/jkjh8/vp_app2/releases)에서 최신 버전을 다운로드합니다
2. **설치**: 다운로드한 설치 파일을 실행합니다
3. **실행**: 설치 완료 후 VP App2를 실행합니다

### 첫 실행

처음 실행하면 다음 포트들이 열립니다:

- **웹 인터페이스**: http://localhost:3000
- **TCP 외부제어**: localhost:15000(단순) / 15001(JSON)

방화벽 경고가 표시되면 액세스를 허용해주세요.

## 기본 사용법

### 파일 추가

1. **메인 화면**에서 "파일 추가" 버튼을 클릭합니다
2. 재생할 미디어 파일을 선택합니다
3. 지원 형식:
   - 비디오: MP4, AVI, MKV, MOV, WMV
   - 오디오: MP3, WAV, FLAC, AAC
   - 이미지: JPG, PNG, GIF, BMP

### 재생 제어

- **재생/일시정지**: 스페이스바 또는 재생 버튼
- **정지**: Stop 버튼
- **다음 트랙**: → 키 또는 Next 버튼
- **이전 트랙**: ← 키 또는 Previous 버튼
- **전체화면**: F11 또는 전체화면 버튼

### 시간 탐색

- **프로그레스 바**: 클릭하여 원하는 위치로 이동
- **키보드**:
  - `→`: 10초 앞으로
  - `←`: 10초 뒤로

## 플레이리스트 관리

### 플레이리스트 생성

1. "플레이리스트" 탭으로 이동합니다
2. "새 플레이리스트" 버튼을 클릭합니다
3. 플레이리스트 이름을 입력합니다
4. 파일을 드래그 앤 드롭하여 추가합니다
5. "저장" 버튼을 클릭합니다

### 플레이리스트 편집

1. 편집할 플레이리스트를 선택합니다
2. "편집" 버튼을 클릭합니다
3. 트랙 순서를 드래그로 변경할 수 있습니다
4. 트랙을 삭제하려면 X 버튼을 클릭합니다
5. "저장" 버튼을 클릭합니다

### 반복 모드

- **없음**: 플레이리스트가 끝나면 정지
- **전체 반복**: 플레이리스트를 반복 재생
- **한 곡 반복**: 현재 트랙을 반복 재생 (플레이리스트 모드에서만)

## 원격 제어

### 웹 인터페이스

브라우저에서 `http://localhost:3000`에 접속하여 원격으로 제어할 수 있습니다.

**모바일 기기에서 접속:**

1. PC와 모바일 기기가 같은 네트워크에 연결되어 있어야 합니다
2. PC의 IP 주소를 확인합니다 (예: 192.168.0.100)
3. 모바일 브라우저에서 `http://192.168.0.100:3000`에 접속합니다

### TCP 제어

외부 프로그램에서 TCP 소켓을 통해 제어할 수 있습니다.

**연결 정보:**

- 호스트: localhost
- 포트: **15000(단순, 쉼표 구분)** / **15001(JSON)** — 각 포트는 해당 형식만 허용
- 프로토콜: TCP, 한 줄당 한 명령(`\n` 구분)

**명령 예시:**

```json
{"command": "player.play"}
{"command": "playlist.play", "id": 1, "track": 0}
{"command": "window.play", "windowId": 2, "index": 0}
```

단순 포트 예시: `player.play` · `playlist.play,1,0` · `mode.set,window`

명령은 `domain.action` 네임스페이스 전용입니다(레거시 flat 명령 없음). 자세한 내용은
[TCP 프로토콜 문서](./TCP_PROTOCOL.md) 또는 [API 매뉴얼](./API_MANUAL.md)을 참조하세요.

## 설정

### 오디오 장치

1. "설정" 메뉴를 엽니다
2. "오디오 장치" 섹션으로 이동합니다
3. 드롭다운 메뉴에서 원하는 출력 장치를 선택합니다
4. 변경사항이 즉시 적용됩니다

### 이미지 표시 시간

이미지 파일을 플레이리스트에 추가한 경우:

1. "설정" 메뉴를 엽니다
2. "이미지 표시 시간" 설정을 찾습니다
3. 원하는 시간(초)을 입력합니다
4. 기본값: 5초

### 전체화면 설정

- **시작 시 전체화면**: 앱 시작 시 자동으로 전체화면으로 전환
- **재생 시 전체화면**: 미디어 재생 시 자동으로 전체화면으로 전환

## 문제 해결

### 파일이 재생되지 않아요

**원인:**

- 지원하지 않는 파일 형식
- 코덱 누락
- 파일 손상

**해결:**

1. 파일 형식을 확인하세요
2. 필요한 코덱을 설치하세요
3. 다른 파일로 테스트해보세요

### 소리가 나지 않아요

**원인:**

- 잘못된 오디오 장치 선택
- 시스템 볼륨이 음소거 상태
- 오디오 드라이버 문제

**해결:**

1. 오디오 장치 설정을 확인하세요
2. 시스템 볼륨을 확인하세요
3. 다른 오디오 장치로 변경해보세요

### 원격 접속이 안 돼요

**원인:**

- 방화벽 차단
- 네트워크 문제
- 포트 충돌

**해결:**

1. 방화벽 설정에서 포트 3000, 15000, 15001을 허용하세요
2. 네트워크 연결을 확인하세요
3. 다른 프로그램이 같은 포트를 사용하지 않는지 확인하세요

### 플레이리스트가 저장되지 않아요

**원인:**

- 디스크 공간 부족
- 권한 문제
- 데이터베이스 오류

**해결:**

1. 디스크 공간을 확인하세요
2. 관리자 권한으로 실행해보세요
3. 앱을 재시작해보세요

### 로그 파일 확인

문제가 지속되면 로그 파일을 확인하세요:

**Windows:**

```
%APPDATA%/eventlog/application-YYYY-MM-DD.log
```

**macOS:**

```
~/Library/Application Support/eventlog/application-YYYY-MM-DD.log
```

**Linux:**

```
~/.config/eventlog/application-YYYY-MM-DD.log
```
